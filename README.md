# HR Tools · ابزارهای منابع انسانی

مجموعه‌ای از ابزارهای ساده و تحت وب برای کارهای روزمره منابع انسانی.
همه ابزارها در مرورگر اجرا می‌شوند و **هیچ داده‌ای ذخیره یا به جایی ارسال نمی‌شود.**

---

## 🧮 ماشین‌حساب حقوق خالص ↔ ناخالص (۱۴۰۵)

تبدیل حقوق خالص به ناخالص (و برعکس) بر اساس قانون بودجه و بخشنامه مزد سال ۱۴۰۵. همه مبالغ به **ریال** است.

### امکانات
- دو حالت محاسبه: **خالص → ناخالص** و **ناخالص → خالص**
- ورود دستی **پایه سنوات**، **بن** و **حق مسکن**
- **حق اولاد** بر اساس تعداد فرزند
- گزینه **حق تأهل**
- تیک **معافیت مالیاتی** (مثلاً برای ایثارگران یا مناطق آزاد/محروم)
- ریز فیش حقوقی: بیمه، درآمد مشمول مالیات، مالیات و خالص پرداختی
- نمایش **هزینه کل کارفرما** و **نرخ مؤثر کسورات**
- جدول پلکان مالیات با مشخص شدن پله فعلی
- تنظیمات پیشرفته برای تغییر نرخ‌ها و سقف‌ها در صورت تغییر بخشنامه

### مبانی محاسبه (پیش‌فرض‌ها)

| مورد | مقدار |
|---|---|
| بن خواربار | ۲۲٬۰۰۰٬۰۰۰ ریال |
| حق مسکن | ۳۰٬۰۰۰٬۰۰۰ ریال |
| حق اولاد (هر فرزند) | ۱۶٬۶۲۵٬۵۵۰ ریال |
| حق تأهل | ۵٬۰۰۰٬۰۰۰ ریال |
| بیمه سهم کارمند | ۷٪ |
| بیمه سهم کارفرما (با بیکاری) | ۲۳٪ |
| سقف مبنای بیمه | ۱٬۱۶۳٬۷۸۸٬۵۰۰ ریال (۷ برابر حداقل دستمزد) |
| سقف معافیت مالیاتی ماهانه | ۴۰۰٬۰۰۰٬۰۰۰ ریال |

**پلکان مالیات ماهانه ۱۴۰۵ (میلیون ریال):**

| بازه | نرخ |
|---|---|
| تا ۴۰۰ | معاف |
| ۴۰۰ تا ۸۰۰ | ۱۰٪ |
| ۸۰۰ تا ۱٬۰۰۰ | ۱۵٪ |
| ۱٬۰۰۰ تا ۱٬۲۰۰ | ۲۰٪ |
| ۱٬۲۰۰ تا ۱٬۴۰۰ | ۲۵٪ |
| بیش از ۱٬۴۰۰ | ۳۰٪ |

### قواعد
- پایه سنوات، بن، مسکن و حق تأهل **مشمول بیمه** هستند؛ حق اولاد مشمول بیمه نیست.
- درآمد مشمول مالیات = حقوق ناخالص − ۲/۷ بیمه سهم کارمند (ماده ۱۳۷ قانون مالیات‌های مستقیم).
- اضافه‌کاری، پاداش و عیدی در این محاسبه لحاظ نشده‌اند.

> ⚠️ این ابزار برای برآورد و برنامه‌ریزی است و جایگزین محاسبه رسمی نرم‌افزار حقوق و دستمزد نیست.
